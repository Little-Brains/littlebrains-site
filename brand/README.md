# Little Brains brand files

Logo A, "Full stop": the name set in Fraunces, ending in a tomato full stop that echoes the homepage line "Games for little brains."

| File | Use it for |
|---|---|
| `littlebrains-logo.svg` / `.png` | The logo on light backgrounds (ink lettering, tomato dot) |
| `littlebrains-logo-white.svg` / `.png` | The logo on dark backgrounds (paper lettering, marigold dot) |
| `littlebrains-mark.svg` | The small mark, "Lb." on an ink square: avatars, favicons, social profiles |
| `littlebrains-mark-1024.png`, `-512.png` | The mark as images, for profile pictures |

The lettering in the SVG files is converted to outlines, so they display correctly anywhere without the font installed. Don't stretch, recolour or re-space the logo. Leave clear space around it of at least the height of the "L".

## Colours

| Name | Hex | Used for |
|---|---|---|
| Ink | `#2B2340` | Lettering, the mark's square |
| Paper | `#FFFDF8` | Lettering on dark |
| Tomato | `#E4644A` | The full stop on light backgrounds |
| Marigold | `#F2B53D` | The full stop on dark backgrounds |
